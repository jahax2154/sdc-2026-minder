# API contract draft

Status: **PROPOSED** discussion inventory. Entities, ownership and workflows are **PENDING** team approval. No endpoints or finalized request/response schemas are defined.

## Potential shared entities

- Profile context: skills, competencies, goals, interests, education, experience and learning constraints.
- Career role, recommendation, skills gap and supporting evidence.
- Chat conversation and context-aware explanation.
- Agent proposal, user acceptance decision and execution history/status.
- Market trend evidence, roadmap, execution task and progress observation.
- Scenario assumptions, projection and explanation; potential SDG mapping.

## Potential workflows

1. Maintain profile context and supply relevant context to authorized product workflows.
2. Explore career recommendations and gaps, vary scenario assumptions and review explanations.
3. Discuss career questions with validated information and profile context.
4. Review bounded agent proposals, accept proposed changes and inspect execution status/history.
5. View trends, roadmaps, actionable tasks and progress, then drill into details.

## Pending agreement

Entity ownership and identifiers; validation and evidence provenance; user-context access and privacy; error conventions; pagination where needed; synchronous versus asynchronous computation; agent acceptance and execution semantics; model versions and uncertainty representation; persistence and contract versioning. Decide these alongside approved mockup flows before defining schemas or implementation.

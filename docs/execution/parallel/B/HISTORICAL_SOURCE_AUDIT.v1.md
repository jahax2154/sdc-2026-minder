The first whole Kaggle download exceeded the collector's 30 MB cap. Its file metadata identified a 166,519,093-byte CSV, so one explicitly bounded 80 MB compressed / 250 MB unpacked acquisition was performed. The actual ZIP is 52,725,731 bytes and its SHA-256 is recorded. This was a diagnosed size-limit change, not an unlimited retry or paid job. The uploader labels the dataset Apache 2.0; third-party advertisement rights and mirror redistribution terms are not independently certified. Raw descriptions remain local.

## Executable outputs

`data_cli market-probe --plan ... --output ...` downloads only finite declared source plans, inspects actual CSV/ZIP/workbook/HTML/JSON responses and records failures. It now bounds link metadata, omits inline image payloads and redacts ephemeral signed-redirect parameters. The committed investigation plans preserve exactly which endpoints were tried. No unbounded crawling occurs.

`data_cli market-corpus-audit --input <pinned-zip> --expected-sha256 <hash> --output ...` produced `ml/data/market/research/jobstreet-corpus-counts.v1.json` from all 69,024 real records. It contains actual frozen-corpus counts by eight listing quarters, partial native role-title matches, technology mentions and a distinct conservative explicit-request-clause subset. Repeated native IDs are deduplicated. Missing periods stay absent. The output explicitly sets `eligible_for_approved_forecasting=false`, `approved_target_rows=[]`, and unknown historical collection/availability. It is a descriptive research compilation, not a different-target trained experiment or a Malaysian demand forecast. No model accuracy is inferred from these counts.

`data_cli market-published-roles --report ... --output ...` produced `ml/data/market/published-role-observations.v1.json`: 35 genuine numeric source-label counts plus 42 missing cells from 11 inspected releases. Extraction checks document hashes, the release's own quarter heading and publication date. It never allocates broad-sector numbers or turns a named-but-uncounted role into zero. Release dates and actual retrieval availability are separate; historical byte availability is not invented.

## Exact missing forecast inputs

For the approved role-advertisement target, B still needs sufficiently long, comparable quarter-level counts of distinct valid ads mapped to a documented role classification, covering the declared collection universe, with actual outcome/publication vintages. Neither broad marginals, top-five publication censoring nor surviving listings supply that complete series.

For each requested-skill target, B still needs quarter-level unique-ad requests from the same declared source universe, dated ad-to-skill evidence or validated extraction, explicit missing/optional/negated states, collection completeness and historical availability. MyNSR requirements and major occupation groups are different measurements. The acquired full descriptions allow a transparent frozen-corpus audit, but do not restore uncollected ads or past availability.

Both families also require enough chronological examples after lag features and label-availability embargo for training, validation and an untouched holdout. No relaxation of Malaysia scope, target units, date controls or source quality was requested. No valid new approved-target real-data learner run is claimed; implementation, source acquisition, corpus compilation, evaluation and application selection remain separate.

B continues current-market serving and A handoffs. A owns personal/numerical decisions and canonical crosswalk acceptance; the user is not being assigned dataset research. RunPod access/balance remains a separate operational dependency, with no paid execution or spend in this investigation.
